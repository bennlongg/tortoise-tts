# (QoL improvements for) TorToiSe

This repo is for my modifications to [neonbjb/tortoise-tts](https://github.com/neonbjb/tortoise-tts). If you need the original README, refer to the original repo.

\> w-where'd everything go?

Please migrate to [mrq/ai-voice-cloning](https://git.ecker.tech/mrq/ai-voice-cloning), as that repo is the more cohesive package for voice cloning.

## Scripts

* `tortoise_tts.py` - The main script for generating audio from text.
* `do_tts.py` - A script that generates audio from text using a specific voice.
* `eval.py` - A script that evaluates the quality of generated audio.
* `get_conditioning_latents.py` - A script that extracts conditioning latents from audio files.
* `is_this_from_tortoise.py` - A script that checks if an audio file was generated by Tortoise.
* `read.py` - A script that reads text from a file and generates audio.
* `convert.bat` - A batch script for converting audio files on Windows.
* `convert.sh` - A shell script for converting audio files on Unix-based systems.
