# Contributing

## Issues

If you have a question or a problem with Tortoise, please [submit an issue](https://github.com/neonbjb/tortoise-tts/issues).

## Pull Requests

If you want to contribute code, please [submit a pull request](https://github.com/neonbjb/tortoise-tts/pulls).

## Coding Standards

Please follow the [PEP 8](https://www.python.org/dev/peps/pep-0008/) coding standards.
